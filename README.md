# AI Resume Screening & Candidate Analytics System
## 📌 Project Overview
The AI Resume Screening & Candidate Analytics System is a Flask-based web application that automates the resume screening process using Machine Learning.
It predicts candidate eligibility based on resume information and stores candidate details in a MySQL database.
---
## 🚀 Features
- Resume Upload
- Resume Parsing
- Candidate Screening
- Machine Learning Prediction
- Recruiter Dashboard
- MySQL Database
- Attractive Web Interface
---
